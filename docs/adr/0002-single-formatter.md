# 0002. 포맷터는 루트 oxfmt 하나

## 맥락

PR #1에서 oxfmt를 도입하고 루트 `.oxfmtrc.json`으로 저장소 전체를 포맷하기로 했다. 서버가 들어오면 서버 프레임워크가
Prettier 설정을 따로 만들어 줄 수 있다.

## 결정

서버를 포함해 저장소 전체가 루트 `.oxfmtrc.json` 하나를 따른다. 서버에는 Prettier 설정이나 의존성을 두지 않는다.

## 근거

- 설정이 한 벌이라 앱마다 조금씩 달라지는 일이 없고, 규칙을 고칠 때 한 곳만 고치면 된다.
- 포맷터가 둘이면 에디터가 저장할 때 하는 포맷과 커밋 때 하는 포맷이 달라 같은 파일이 계속 바뀐다.
- 앱 사이에서 파일을 옮겨도 스타일이 바뀌지 않는다.
- 새 앱이나 패키지를 추가해도 포맷 설정을 만들 필요가 없고, lint-staged와 CI 검사가 단순하다.

## 검토한 대안

`apps/web`에만 적용하고 서버 포맷은 서버 담당자가 따로 정하는 방식. 설정이 둘로 나뉘고 앱 사이 스타일이 달라져서
제외했다.

## 결과와 후속

린트는 포맷과 별개다. 공통 규칙은 루트에 두고 앱 환경별 규칙(web은 React, server는 비동기 규칙 등)은 앱마다 추가하는
방식을 서버 세팅 때 정한다.
