# 작업 규칙

저장소에서 일하는 사람과 AI 에이전트가 지키는 운영 규칙을 주제별로 한 파일씩 둔다. 기술 결정 자체와 그 근거는
[adr/](../adr/README.md)에(작성 규칙은 [adr.md](adr.md)), 커밋·브랜치 규칙은 [CONTRIBUTING.md](../../CONTRIBUTING.md)에
있다. 여기에는 옮겨 적지 않는다.

| 문서                           | 내용                                          | 읽을 때               |
| ------------------------------ | --------------------------------------------- | --------------------- |
| [work-files.md](work-files.md) | 작업 파일의 위치·양식·상태, 완료 후 정리 방법 | 작업을 시작·마칠 때   |
| [adr.md](adr.md)               | ADR의 파일명·상태·양식, 대체 정책             | 기술 결정을 기록할 때 |

규칙이 늘면 주제별로 파일을 추가하고 위 표에 한 줄을 더한다.
