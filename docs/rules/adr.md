# ADR 작성 규칙

기술 결정을 한 건에 한 파일로 [adr/](../adr/README.md)에 남긴다. 결정만이 아니라 왜 그렇게 정했는지와 검토한 대안을 함께
적는다. 결정을 바꾸면 기존 파일을 고치지 않고 새 ADR을 추가해 "대체됨"으로 표시한다.

## 위치와 이름

- 파일 이름은 `NNNN-kebab-case.md`다. 번호는 마지막 ADR의 다음 번호를 쓴다.
- 만들면 [adr/README.md](../adr/README.md)의 목록에 한 줄을 추가한다.

## 양식

```markdown
---
title: 제목
status: 확정 | 제안 | 대체됨
date: YYYY-MM-DD
---

# NNNN. 제목

## 맥락

## 결정

## 근거

## 검토한 대안

## 결과와 후속
```

## 쓰는 방법

- 아직 합의하지 못한 결정은 상태를 "제안"으로 두고, "결과와 후속"에 정하지 않은 것을 적는다.
- 확인하지 못한 사실(공식 문서를 읽지 못한 경우 등)은 ADR에 그대로 밝힌다.
- 운영 규칙(작업 파일, 문서 작성 방법)은 ADR이 아니라 [rules/](README.md)에 둔다.
