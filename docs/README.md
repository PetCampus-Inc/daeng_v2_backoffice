# 문서 지도

프론트와 서버가 함께 보는 문서를 둔다. 앱 하나에만 해당하는 문서는 그 앱 안에 둔다(예:
[apps/web/docs/](../apps/web/docs/folder-structure.md)).

| 문서                                     | 내용                                                    | 읽을 때 / 남길 때                                                                                |
| ---------------------------------------- | ------------------------------------------------------- | ------------------------------------------------------------------------------------------------ |
| [api-conventions.md](api-conventions.md) | 프론트·서버가 합의할 API 공통 규약 초안                 | API를 만들거나 바꿀 때 읽는다. "아직 정하지 않은 것"은 사람에게 묻는다. 규약이 확정되면 반영한다 |
| [adr/](adr/README.md)                    | 결정 기록(ADR). 결정마다 맥락·근거·검토한 대안을 남긴다 | 기술 결정이 확정되면 기록한다                                                                    |
| `work/`                                  | 진행 중인 작업의 범위·완료 기준·검증 결과               | 여러 단계로 진행하는 작업을 시작하거나 결과를 남길 때 읽고 갱신한다                              |
| [rules/](rules/README.md)                | 작업 규칙(작업 파일 위치·양식·정리 등)                  | 작업을 시작하거나 마칠 때 읽는다                                                                 |
| `product/`                               | 기획 요구사항 원문(추가 예정)                           | —                                                                                                |

같은 내용을 두 곳에 쓰지 않는다. 다른 문서에서는 링크로 가리킨다.
