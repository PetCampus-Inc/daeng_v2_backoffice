# 13. 원장 인증 현황

범위: 7.16 기존 조회 화면 중 원장 인증 현황, 4.1 권한, 4.2 화면 틀, 4.4 목록 공통, 4.5 화면 상태, 2.2 제외 항목(원장
인증 심사는 4.0 에픽 KD3-567).

7.16은 이 화면을 '개편안 구현 그대로' 둔다고 한다. 그래서 기준은 기존 화면
`daeng_discord/public/service-admin.html`(이하 service-admin.html)의 원장 인증 현황이고, 칸 값의 뜻은 기존 서버 코드
`apps/daeng-admin/service-admin.js`를 따랐다. API는 백엔드가 새로 만든다. 상세는 따로 화면이 아니라 목록 오른쪽
패널이다. 연락처·사업자번호 가리기는 `11-회원.md` R-가림을 쓴다.

---

## R-인증탭. 단계 탭 (7.16, service-admin.html 기준)

입력: 탭, `인증-기본`. 기대값: 결과(제출일 최신순).

| ID          | 탭              | 결과                                   |
| ----------- | --------------- | -------------------------------------- |
| R-인증탭-01 | 전체            | 김신청, 이원장, 박원장, 최해지, 정입력 |
| R-인증탭-02 | 사업자번호 대기 | 김신청                                 |
| R-인증탭-03 | 인증 완료       | 이원장, 박원장                         |
| R-인증탭-04 | 해지됨          | 최해지                                 |

- '유치원 정보 입력' 단계는 탭이 없어 '전체'에서만 보인다(기존 그대로).
- 제출일이 없는 건(정입력)의 순서 (보류: 기존 API는 제출일이 없으면 인증 번호로 정렬 값을 대신해 순서가 일정하지 않다.
  맨 뒤로 둘지 정해야 한다)

## 원장 인증 현황 (7.16)

### S-인증-001. 원장 인증 현황을 연다 (7.16, service-admin.html 기준)

- 실행: 브라우저 확인
- 로그인: 조회자
- 데이터: `인증-기본`
- 시작: 원장 인증 현황
- 행동: 화면을 연다
- 확인:
  - 제목 `원장 인증 현황`, 아래 회색 `자동 사업자 인증과 원장 권한 연결 상태를 조회합니다.`
  - 왼쪽 표 카드, 오른쪽 상세 패널(폭 390px)
  - 표 카드 위쪽 탭: `전체` · `사업자번호 대기` · `인증 완료` · `해지됨`, '전체' 선택(주황 밑줄)
  - 툴바: 검색(안내 글자 `신청자 또는 유치원 검색`) → 정렬 드롭다운 → 오른쪽 끝 `총 5건` (PRD 4.4)
  - 표 열: 신청자 | 유치원 | 지역 | 신청일 | 대기 시간
  - 행 순서: 김신청, 이원장, 박원장, 최해지, 정입력
  - 상세 패널 가운데 ☝ + 회색 `왼쪽에서 인증 건을 선택해주세요.`
  - 브레드크럼 없음, 사이드바 '고객 관리 > 원장 인증 현황' 강조 (4.2)
  - 브라우저 탭 제목 `원장 인증 현황 · 똑독 BO` (4.2)

### S-인증-002. 행 칸 모양을 본다 (7.16, service-admin.html 기준)

- 행동: 화면을 아래로 스크롤한다
- 확인:
  - 경우별 배치
  - 가로 스크롤은 표 안에서만 생긴다

### S-인증-019. 세 역할 모두 원장 인증 현황을 연다 (4.1)

- 실행: E2E
- 로그인(경우마다 따로): 최고관리자 / 운영자 / 조회자
- 데이터: `인증-기본`
- 시작: 원장 인증 현황(주소 직접 입력)
- 행동: 화면을 연다
- 확인:
  - 권한 없음 화면 없이 5건이 보인다
  - 사이드바에 '고객 관리 > 원장 인증 현황'이 있다

### S-인증-020. 원장 인증 현황이 기존 화면과 같다 (FR-BO-111, 7.16)

- 실행: 수동 (기존 화면 회귀 — 기준이 service-admin.html 원장 인증 현황이다)
- 로그인: 조회자
- 시작: 새 BO 원장 인증 현황과 기존 화면 원장 인증 현황을 나란히 연다
- 행동: 같은 운영 데이터로 탭을 바꾸고 여러 행의 상세 패널을 연다
- 확인:
  - 탭 결과, 행 순서, 상세 패널 값(가린 연락처·사업자번호 포함)이 같다
  - 이 문서의 보류 항목과 PRD 4.4·4.5를 따르는 항목(날짜 형식, 건수 표시, 페이지 이동, 화면 상태)은 비교에서 뺀다

### F-인증-01. 단계별로 인증 건을 골라 상세를 본다 (7.16)

- 로그인: 조회자 / 데이터: `인증-기본`

1. 사이드바 '고객 관리 > 원장 인증 현황' → 5건, 패널 `왼쪽에서 인증 건을 선택해주세요.`
2. '인증 완료' 탭 → 이원장, 박원장
3. 박원장 행 클릭 → 패널 제목 `박원장`, 사업자번호 `***`, 연락처 `미등록`
4. '해지됨' 탭 → 최해지만, 패널이 처음 안내로 돌아간다
5. 최해지 행 클릭 → 현재 단계 `해지됨`, 처리 버튼 없음
