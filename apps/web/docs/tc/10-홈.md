# 10. 홈

범위: 7.16 기존 조회 화면 중 홈(개편안 대시보드), 4.1 권한, 4.2 화면 틀, 4.5 화면 상태, 2.2 제외 항목(대시보드 그래프
기간 변경은 2단계).

7.16은 이 화면을 '개편안 구현 그대로' 둔다고 한다. 그래서 기준은 기존 화면
`daeng_discord/public/service-admin.html`(이하 service-admin.html)의 대시보드이고, 숫자의 뜻은 기존 서버 코드
`apps/daeng-admin/service-admin.js`를 따랐다. API는 백엔드가 새로 만든다. 새 API 스펙이 나오면 응답 모양만 맞추고 확인
값은 그대로 둔다.

## R-홈인증수. 원장 인증 단계별 수 (7.16, service-admin.html 기준)

판정: 서버. 입력: 인증 단계별 건수(유치원 정보 입력, 사업자번호 대기, 인증 완료, 해지됨). 기대값: 인증 진행 중, 전체
인증 기록.

| ID            | 유치원 정보 입력 | 사업자번호 대기 | 인증 완료 | 해지됨 | 인증 진행 중 | 전체 인증 기록 |
| ------------- | ---------------- | --------------- | --------- | ------ | ------------ | -------------- |
| R-홈인증수-01 | 3                | 9               | 150       | 4      | 12           | 166            |
| R-홈인증수-02 | 0                | 0               | 0         | 0      | 0            | 0              |
| R-홈인증수-03 | 5                | 0               | 0         | 0      | 5            | 5              |
| R-홈인증수-04 | 0                | 0               | 10        | 2      | 0            | 12             |
| R-홈인증수-05 | (건 없음)        | 2               | 1         | 0      | 2            | 3              |

- 인증 진행 중 = 유치원 정보 입력 + 사업자번호 대기('사업자 인증 완료 전'). 해당 단계에 건이 없으면 0으로 센다.
- '해지된 원장' 카드는 해지됨 건수다. 해지됨이 0건이면 '원장 역할이 해지된 회원 수'로 바꿔 보여 준다(기존과 같게,
  2026-10-22 결정).

### S-홈-001. 홈을 연다 (7.16, service-admin.html 기준)

- 실행: 브라우저 확인
- 로그인: 조회자
- 데이터: `홈-기본`
- 시작: `/home`
- 행동: 화면을 연다
- 확인:
  - 제목 `서비스 대시보드`, 아래 회색 `회원 가입과 유치원 운영 현황을 한눈에 확인하세요.`
  - 지표 카드 6개, 왼쪽부터: `전체 회원` → `견주 회원` → `활성 원장` → `원장 연결 유치원` → `인증 진행 중` →
    `해지된 원장`
  - 카드 아래: 왼쪽 넓게 '신규 가입 추이', 오른쪽 '최근 원장 인증', 그 아래 폭 전체 '원장 인증 구성'
  - 브레드크럼 없음, 사이드바 '홈' 강조 (4.2)
  - 브라우저 탭 제목 `서비스 대시보드 · 똑독 BO` (4.2)

### S-홈-018. 첫 조회·재방문 중 집계와 배치가 안정적이다
