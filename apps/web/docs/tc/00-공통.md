# 00. 공통

여러 기능에 걸치는 규칙과, 특정 기능에 속하지 않는 화면 동작(화면 틀, 권한 없음 화면, 세션 만료 등)이다.

근거: PRD 4장(공통 정책), 5.5(배지 색), 10장(놓치기 쉬운 점).

- 행동: 사이드바의 1:1 문의와 아이디어 제안을 빠르게 차례로 선택하고 브라우저 뒤로·앞으로 이동한다
- 확인:
  - 진행 상태가 보이고 마지막 목적지의 URL·제목·현재 메뉴 강조·본문이 일치한다
  - 늦게 끝난 이전 화면의 조회가 현재 화면을 덮어쓰지 않는다
  - 화면 이동 후 키보드 초점이 제거된 요소에 방치되지 않고 새 화면의 조작을 이어갈 수 있다
  - 프로필·알림 팝오버와 좁은 창 메뉴가 이동 후 본문을 가리거나 겹쳐 남지 않는다

### S-공통-019. 이탈 확인 취소가 입력·포커스·스크롤을 보존한다

- 실행: E2E
- 로그인: 운영자
- 데이터: `문의-기본`
- 시작: 문의 상세(#1043)
- 준비: 답변을 입력하고 중간 커서·스크롤을 기록한다
- 행동: 다른 메뉴를 눌러 이탈 확인창을 열고 Tab·Shift+Tab 뒤 [취소] 또는 Esc로 닫는다(경우마다 따로)
- 확인:
  - 확인창이 한 번만 열리고 제목·설명이 인식되며 초점은 확인창 안에서 이동한다
  - 취소 후 원래 화면·입력·커서·스크롤이 유지되고 이어서 조작할 위치로 초점이 돌아온다
  - 배경 메뉴를 실행하거나 확인창 없이 입력을 버리지 않는다
  - 이어서 [나가기]를 선택하면 의도한 목적지로 한 번 이동하고 확인창이 남지 않는다

### S-공통-020. 세션·역할 전환에서 오래된 화면과 안내가 섞이지 않는다

- 실행: E2E
- 로그인: 운영자
- 데이터: `문의-기본`
- API(경우마다 따로): 여러 요청 중 세션 만료 응답 / 권한 변경 응답, 기존 조회는 2초 늦게 도착
- 시작: 문의 상세(#1043)
- 준비: 답변을 입력하고 기존 S-공통-014~015의 거부 조건을 만든다
- 행동: 답변 저장 요청을 보낸다
- 확인:
  - 기존 정책대로 로그인 또는 권한 없음 화면으로 이동하며 이탈 확인창·중복 안내가 겹치지 않는다
  - 이동 후 늦은 응답이 이전 계정의 데이터·프로필·메뉴를 다시 노출하지 않는다
  - 안내를 읽고 키보드로 재로그인 또는 [홈으로 이동]을 실행할 수 있다
  - 재로그인 후 메뉴·권한·현재 계정이 일치하고 이전 초안은 기존 정책대로 남지 않는다

### S-공통-021. 오류·실행 취소 안내가 조작을 가리지 않는다

- 실행: E2E
- 로그인: 운영자
- 데이터: `문의-기본`

  - 표시 시간은 R-토스트를 따르고 별도 문구·보존 정책을 추가하지 않는다
