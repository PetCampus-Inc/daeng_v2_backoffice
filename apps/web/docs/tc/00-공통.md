# 00. 공통

여러 기능에 걸치는 규칙과, 특정 기능에 속하지 않는 화면 동작(화면 틀, 권한 없음 화면, 세션 만료 등)이다.

근거: PRD 4장(공통 정책), 5.5(배지 색), 10장(놓치기 쉬운 점).
