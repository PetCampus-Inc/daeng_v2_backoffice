  맞춘다.

- 행동: 게시 → 변경 저장 → 게시 해제 → 재게시를 차례로 한다
- 확인:
  - 게시하면 앱에 바로 보이고 푸시가 가지 않는다
  - 변경 저장하면 앱에 바뀐 내용이 보인다
  - 게시 해제하면 앱에서 바로 사라진다
  - 재게시하면 다시 보이고 순서(최초 게시일 기준)가 그대로다

## 흐름

### F-공지-01. 공지를 작성해 게시하고 관리한다 (3.4)

- 로그인: 운영자 / 데이터: `공지-기본`

1. 앱 공지 목록 → [새 공지 작성] → 제목 `11월 점검 안내`, 본문 `11월 5일 점검합니다` 입력 → 미리보기에 보인다
2. [초안 저장] → 토스트 `초안을 저장했습니다.`, 주소가 #15로 바뀜, 제목 `초안 수정`
3. [공지 게시] → 확인창 `제목: 11월 점검 안내` → [공지 게시] → 게시 완료 화면
4. [공지 보기] → #15 읽기 화면, 상태 '게시', 게시일 `2026. 10. 07.`
5. [수정] → 본문 끝에 ` 오전 2시` 입력 → [변경 저장] → 읽기 화면, 게시일 그대로
6. [게시 해제] → '게시 해제' 읽기 화면, 토스트가 사라질 때까지 둔다
7. [공지 재게시] → [공지 재게시] → 상태 '게시', 게시일 `2026. 10. 07.` 그대로
8. 앱 공지 목록 → 순서 #14, #13, #15, #12, #11, #10

### F-공지-02. 저장 없이 바로 게시하고 목록 자리를 확인한다 (3.4, 7.7)

- 로그인: 운영자 / 데이터: `공지-기본`

1. [새 공지 작성] → 제목 `긴급 공지`, 본문 `오늘 점검합니다` → [공지 게시] → [공지 게시] → 게시 완료 화면
2. [목록으로] → #15가 초안 아래 게시 공지 맨 위(#14, #13, #15, #12, #11, #10)
3. #12 `게시 해제` → [실행 취소] → #12 자리 그대로

### F-공지-03. 초안을 만들었다가 지운다 (5.3)

- 로그인: 운영자 / 데이터: `공지-기본`

1. [새 공지 작성] → 제목 `임시` → [초안 저장] → #15 초안
2. [초안 삭제] → [초안 삭제] → 앱 공지 목록, 토스트 `초안을 삭제했습니다.`, #15 없음
3. 상태 '초안' 필터 → #14, #13
