# 04. 아이디어 제안

범위: 7.5 제안 목록, 7.6 제안 상세. 조회 전용(처리 상태·담당자·분류 없음).

---

## R-제안정렬. 목록 정렬 (7.5)

입력: 정렬, `제안-기본`. 기대값: 순서.

| ID            | 정렬               | 순서                         |
| ------------- | ------------------ | ---------------------------- |
| R-제안정렬-01 | 제출일시 최신순    | #350, #349, #348, #347, #346 |
| R-제안정렬-02 | 제출일시 오래된 순 | #346, #347, #349, #348, #350 |

- #349와 #348은 제출일시가 같아 두 방향 모두 번호 큰 #349가 먼저다(`00-공통.md` R-목록).

## R-제안검색. 검색·필터 (7.5)

입력: 검색어, 사용자 유형, `제안-기본`. 기대값: 결과.

| ID            | 검색어      | 사용자 유형 | 결과             |
| ------------- | ----------- | ----------- | ---------------- |
| R-제안검색-01 | `산책 코스` | 전체        | #350             |
| R-제안검색-02 | `DAILY`     | 전체        | #349             |
| R-제안검색-03 | `홍길동`    | 전체        | #350, #346       |
| R-제안검색-04 | (빈 값)     | 원장        | #349, #347       |
| R-제안검색-05 | (빈 값)     | 보호자      | #350, #348, #346 |
| R-제안검색-06 | `좋겠어요`  | 원장        | #347             |
| R-제안검색-07 | `없는말`    | 전체        | (없음)           |

- '사용자 계정' 검색은 `fixtures.md`의 계정 값(사용자 이름)으로 한다. 계정이 이메일까지 뜻하는지는 PRD에 없다.

## 제안 목록 (7.5)

### S-제안-001. 제안 목록을 연다 (FR-BO-070)

- 실행: 브라우저 확인
- 로그인: 조회자
- 데이터: `제안-기본`
- 시작: 아이디어 제안 목록
- 행동: 화면을 연다
- 확인:
  - 툴바 순서: 검색(안내 글자 `내용, 사용자 계정`) → 사용자 유형 → 오른쪽 끝 `총 5건`
  - 표 열: 제안 번호 | 내용 | 사용자 | 제출일시 ↓
  - 사용자 칸 `보호자 · 홍길동` 형식
  - #350 내용이 칸 폭에 맞춰 한 줄에서 말줄임(…), 줄바꿈도 한 줄로 보인다
  - 상태·담당자·분류 열과 필터가 없다
  - 제출일시 `2026. 10. 07. 09:00` 형식
  - 브레드크럼 없음, 사이드바 '아이디어 제안' 강조
