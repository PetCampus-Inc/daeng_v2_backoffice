# 12. 유치원

범위: 7.16 기존 조회 화면 중 유치원, 4.1 권한, 4.2 화면 틀, 4.4 목록 공통, 4.5 화면 상태, 2.2 제외 항목('+ 유치원 등록'
버튼 제거).

7.16은 이 화면을 '개편안 구현 그대로' 둔다고 한다. 그래서 기준은 기존 화면
`daeng_discord/public/service-admin.html`(이하 service-admin.html)의 유치원 관리이고, 칸 값의 뜻은 기존 서버 코드
`apps/daeng-admin/service-admin.js`를 따랐다. API는 백엔드가 새로 만든다. 조회 전용이라 상세 화면이 없다.

## 유치원 목록 (7.16)

### S-유치원-001. 유치원 화면을 연다 (7.16, service-admin.html 기준)

- 실행: 브라우저 확인
- 로그인: 조회자
- 데이터: `유치원-기본`
- 시작: 유치원
- 행동: 화면을 연다
- 확인:
  - 제목 `유치원 관리`, 아래 회색 `등록된 유치원과 운영 상태를 관리합니다.`
  - 표 카드 위쪽 탭: `전체` · `운영 중` · `폐업`, '전체' 선택(주황 밑줄)
  - 툴바 순서: 검색(안내 글자 `유치원명, 원장명 또는 지역 검색`) → 오른쪽 끝 `총 4건` (PRD 4.4)
  - 표 열: 유치원 | 대표 원장 | 지역 | 운영 상태 | 원생 | 사업자 인증 | (이름 없는 열, 행마다 `⋯`)
  - 행 순서(등록일 최신순): 햇살유치원, 달빛유치원, 별빛유치원, 도담유치원
  - 브레드크럼 없음, 사이드바 '고객 관리 > 유치원' 강조 (4.2)
  - 브라우저 탭 제목 `유치원 관리 · 똑독 BO` (4.2)

### S-유치원-002. 행 칸 모양을 본다 (7.16, service-admin.html 기준)

- 실행: 브라우저 확인
- 로그인: 조회자
- 데이터: `유치원-기본`
- 시작: 유치원
- 행동: 화면을 연다
- 확인:
  - 유치원 칸: 이름 첫 글자 동그라미 → 진한 이름 / 아래 회색 `SCHOOL-{ID}` (햇살유치원 `SCHOOL-104`)
  - 대표 원장 칸: 햇살유치원 `이원장`, 별빛유치원·도담유치원 `원장 미연결`
  - 지역 칸: 주소 전체 (햇살유치원 `서울 마포구 망원동 1`)
  - 운영 상태 칸: 운영 중이면 `활성` 초록 점, 도담유치원 `폐업` 빨간 점
  - 원생 칸: `12명` + 회색 작은 `대기 2` (햇살유치원), 별빛유치원 `0명` + `대기 0`
  - 사업자 인증 칸: 햇살유치원·도담유치원 `인증` 초록 점, 달빛유치원·별빛유치원 `미인증` 노란 점

### S-유치원-017. 미방문 조건을 조회하는 동안 기존 표를 유지한다

- 실행: E2E
- 로그인: 조회자
- 데이터: `유치원-기본` (페이지 전환은 `유치원-25건`)
- API: 전환 후 목록 요청이 1.2초 늦게 응답
- 시작: 유치원
- 준비: 격리된 새 컨텍스트에서 전체 목록의 첫 응답을 기다린다
- 행동(경우마다 따로):
  - 처음 '운영 중' 탭을 누른다
  - 처음 '폐업' 탭을 누른다
  - 검색어 `서울`을 입력한다
  - 페이지 번호 `2`를 누른다
- 확인:
  - 응답 대기 중 기존 행과 표의 위치·높이가 유지된다
  - 전환 중 DOM을 관찰해도 표가 제거되거나 회색 로딩 막대로 교체되지 않는다
  - `조회 중…`이 보이며 이전 건수를 새 조건의 결과 건수처럼 표시하지 않는다
  - 대기 중 이전 결과에 의존하는 페이지 이동은 비활성이다
  - 완료되면 선택 조건에 맞는 행·건수·페이지가 표시된다

### S-유치원-018. 탭을 빠르게 바꾼 뒤 마지막 조건의 결과를 표시한다

- 실행: E2E
- 로그인: 조회자
- 데이터: `유치원-기본`
- API: 운영 중 응답은 2초, 폐업 응답은 1초 지연
- 시작: 유치원
- 준비: 격리된 새 컨텍스트에서 전체 목록의 첫 응답을 기다린다
- 행동: '운영 중'을 누른 직후 응답 전에 '폐업'을 누른다
- 확인:
  - 대기 중 표가 사라지지 않는다
  - 두 요청이 모두 완료된 뒤에도 '폐업'이 선택되고 도담유치원 1곳, `총 1건`이 표시된다
  - 늦게 도착한 운영 중 응답이 폐업 결과를 덮어쓰지 않는다

### S-유치원-019. 검색 입력과 커서가 조회 중에도 끊기지 않는다

  - 한글 IME 조합은 별도 브라우저 확인으로 판정하고 일반 문자 입력 자동 테스트로 대체하지 않는다
