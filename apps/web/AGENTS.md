# 웹 작업 지침

이 파일은 `apps/web/` 작업의 문서 진입점이다. [루트 공통 지침](../../AGENTS.md)을 함께 적용한다.

## 기본 작업 지침

- 웹 작업 전에는 [웹 기여 가이드](CONTRIBUTING.md)를 읽고 적용한다.
- `src/`의 파일 생성·이동·공유 범위 변경 전에는 [폴더 구조 규칙](docs/folder-structure.md)을 읽고 적용한다.
- 이 폴더에 `AGENTS.local.md`가 있으면 추가로 읽고 적용한다. 개인 경로·비공개 작업 자료·로컬 환경 설정은 이 파일에서
  관리한다. 없으면 생성을 요구하지 않는다. 이 참조는 프로젝트 규칙이며 도구의 자동 파일 탐색 기능을 뜻하지 않는다.

## 테스트 문서의 역할과 읽는 순서

검사 명령을 선택하거나 검증 범위를 넓히기 전에는 먼저
[웹 테스트 가이드의 검증 범위 선정](docs/testing-guide.md#검증-범위-선정)을 확인한다. 아래 문서는 범위 선정부터 필요한
TC 작성과 검사 실행까지 순서대로 안내한다.

화면 구현·상호작용 수정·검증 작업은 아래 순서로 필요한 문서를 확인한다. 세 문서는 검증의 기준, TC 작성법, 실행 명령을
나누어 관리한다. 매 작업에서 세 문서를 모두 읽거나 모든 TC를 실행하라는 뜻은 아니다.

| 순서 | 문서                                                          | 역할                                                           | 읽는 시점                                        |
| ---- | ------------------------------------------------------------- | -------------------------------------------------------------- | ------------------------------------------------ |
| 1    | [웹 테스트 가이드](docs/testing-guide.md)                     | 변경 영향에 따른 검증 선택, 사용성 점검, 결과 기록과 완료 판정 | 화면 구현·상호작용 수정·테스트 실행 전           |
| 2    | [TC 작성 규칙](docs/test-case-writing-rules.md)               | R·S·F 분류, ID·양식, 준비 조건과 기대 결과 작성                | 관련 TC를 새로 쓰거나 수정할 때                  |
| 3    | [브라우저 검사 실행 안내](docs/browser-test-running-guide.md) | 기존 브라우저 스크립트의 준비 환경·실행 명령·산출물            | 선택한 검증에 브라우저 스크립트 실행이 필요할 때 |

1번에서 변경에 해당하는 R·S·F 검증을 고른다. 기존 TC로 충분하면 2번의 작성 단계는 생략한다. 브라우저 스크립트를 실행하지
않는 작업은 3번을 생략한다. TC의 계정·입력·기대값을 정할 때는 [공통 데이터 정의](docs/tc/fixtures.md)를 추가로 확인한다.
